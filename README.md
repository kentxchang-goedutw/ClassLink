# 🏫 區網互動工具整合版（ClassLink）

**ClassLink** — 把三個獨立開發的區網互動教學工具整合成**一個啟動中心**：教師雙擊 `啟動程式.bat`，在跳出的視窗中選擇這堂課要用哪一個工具和學生互動，不需要記住三個不同的資料夾與啟動程式。

| 工具 | 一句話說明 | 預設連接埠 |
|------|-----------|-----------|
| 🦋 [紫斑之翼 RPG 答題遊戲](#-紫斑之翼rpg-答題遊戲) | JRPG 闖關答題，適合考前複習、隨堂測驗 | 8080 |
| 🧩 [WEB 區網互動工具箱（剛好系列）](#-web-區網互動工具箱剛好系列) | 搶答／投票／白板／簡報／測驗＋作業繳交系統 | 8000 |
| 🖍️ [螢幕畫筆 · 截圖互動](#-螢幕畫筆截圖互動) | 觸控大屏畫記、截圖出題、iPad 即時作答 | 8000 |

三個工具都是**完全在區域網路運作**，不需要 Firebase、雲端帳號或網際網路（只有第一次自動安裝 Python／套件時需要網路），資料全部存在教師電腦本機。

## 🚀 啟動中心使用方式

1. 雙擊 **`啟動程式.bat`**。
   - 找不到 Python 時會自動安裝（先試 winget，失敗再從 python.org 下載官方安裝檔，不需要系統管理員權限）。第一次安裝完成後請**關閉視窗、再雙擊一次**。
   - 自動檢查／修復 pip，並安裝三個工具需要的全部套件：`PyQt5`、`PyQtWebEngine`、`qrcode`、`Pillow`。
2. 出現「教師啟動中心」視窗後，按下想要使用的工具卡片上的 **▶ 啟動**。
3. 工具視窗開啟後，啟動中心會自動縮小；關閉該工具視窗後，啟動中心會自動回到最前面，可以再選擇其他工具。

### 小技巧

- **同時使用多個工具**：可以。啟動中心會自動避開已被占用的連接埠（例如 WEB 工具用 8000、螢幕畫筆改用 8001）。學生請掃描**各工具自己視窗中顯示的 QR Code**，不同工具的網址並不相同。
- **直接啟動某個工具**（適合做成桌面捷徑，開啟後不會先看到選擇畫面）：
  ```
  啟動程式.bat game    ← RPG 答題遊戲
  啟動程式.bat web     ← WEB 區網互動工具箱
  啟動程式.bat pen     ← 螢幕畫筆
  ```
- 每張卡片的 **📂 資料夾** 按鈕可直接開啟該工具的資料夾（題庫、學生作業、遊戲資料都在裡面，換電腦教學時整份複製過去即可保留資料）。
- 第一次啟動工具時，Windows 防火牆可能詢問是否允許存取，請勾選「**私人網路**」並允許，否則學生裝置連不進來。

### 📂 資料夾結構

```text
區網工具整合版/
├── 啟動程式.bat                 # 一鍵啟動器（自動安裝 Python 與套件，再開啟啟動中心）
├── 區網互動工具整合版.py         # 教師啟動中心（選擇要使用的工具）
├── README.md
└── tools/
    ├── RPG答題遊戲/                 # 紫斑之翼 RPG 答題遊戲（資料在 Game-data/）
    ├── WEB區網互動工具(剛好系列)/    # WEB 區網互動工具箱（資料在 www/）
    └── 螢幕畫筆截圖互動/             # 螢幕畫筆‧截圖互動（題庫在 題庫/）
```

每個工具都以獨立程序執行，保有原本完整的功能與資料，彼此互不干擾，也可以直接用 Python 進入各資料夾單獨執行主程式，不透過啟動中心。

## 🦋 紫斑之翼RPG 答題遊戲

**《紫斑之翼：奇幻大遷徙》** — 結合台灣紫斑蝶生態遷徙與熱血動漫風格的教學互動 JRPG 答題遊戲。學生化身守護勇者，靠解答各科題目累積能量、闖過五大關卡魔王，適合**課堂複習、隨堂測驗、資訊融入教學**。題庫不限生態主題，任何學科都能自訂套用。

### 遊戲特色

- **四大守護勇者**：小紫（幻紫遊俠，高爆發）、阿圓（圓翅巨盾戰士，高體力）、阿斯（斯氏靈智賢者，高魔力回復）、端端（端紫幻影刺客，高敏捷），各有專屬技能與立繪。
- **五大關卡地圖**：茂林幽谷、月世界惡地、濁水溪河谷、國道生態廊道、繁衍聖林，可鍵盤或點擊移動，關卡各有專屬 BGM。
- **雙入口首頁**：學生點「🎮 進入遊戲」直接開始；教師點「⚙️ 教師 / 管理者題庫後台」輸入密碼進入後台，互不干擾。
- **答題倒數與魔王反擊**：答題進度條由綠轉紅，時間到魔王會自動反擊扣血，提升專注度。
- **題庫隨機亂序**：每次作答題目順序自動打亂，避免死記位置。
- **五關全破慶祝畫面**：手動點擊才會跳轉到結算報告，方便師生合影留念。

### 教師後台（五大模組）

首頁或大地圖左上角點「⚙️ 教師 / 管理者題庫後台」，輸入預設密碼 **`admin`**：

1. **📚 題庫管理與派送**：可自訂任意學科題庫分類；支援標準 CSV 批次匯入（`題目,正確答案(1-4),選項1,選項2,選項3,選項4,題目解析`）；內建 Gemini／ChatGPT AI 出題 Prompt 模板，貼上教材重點即可自動產題；也可逐題線上編輯。
2. **🎯 主題測驗管理**：可跨題庫自由組卷（例如合併「基礎題庫」＋「進階題庫」），並用「啟用／停用」開關控制學生端是否看到某份測驗。
3. **📊 學生作答分析與錯題本**：
   - 作答歷程分頁：依時間列出姓名、角色、分數、答對題數，可展開查看每題作答細節。
   - 錯題難度排行榜：依答錯人數排序，顯示每題答對率與選項分布，列出誤選學生名單與其錯誤選項——直接看出全班的迷思概念。
   - 課堂全螢幕簡報模式：大字體投影，快捷鍵 `H` 隱藏／顯示答案，`←` `→` 切題、`Esc` 退出，適合公開檢討。
4. **🦋 勇者與關主數值調整**：可微調四大勇者與五大魔王的 HP／MP／攻擊力／爆擊率，依學生程度調整難度。
5. **🖼️ 全域美術客製與 AI 生圖**：可單張上傳或用 ZIP 批次取代全部 20 張圖片（勇者立繪／頭像、魔王立繪、關卡背景），支援雙向智慧回退（只上傳立繪會自動連動頭像，反之亦然），並內建「風格＋主題」AI 生圖 Prompt 產生器，一鍵複製 20 張圖的提示詞交給 AI 工具產圖，即可把整個遊戲換成任何主題皮膚（三國、太空、海洋生物等）。

### 使用方式

1. 從整合啟動中心按「▶ 啟動」（或執行 `啟動程式.bat game`），會開啟 PyQt5 控制面板。
2. 面板點「顯示 QR Code」，學生用平板／手機掃描或輸入顯示的區網網址即可進入遊戲首頁。
3. 若連接埠被占用，可在面板下拉選單切換為 8080／8000／8888／5000／3000 等常用埠，按「重新啟動伺服器」套用。
4. 學生端：輸入姓名、選擇勇者與測驗主題後開始闖關；教師端可隨時開後台查看即時作答數據。

### 資料儲存位置

- `tools/RPG答題遊戲/Game-data/`：題庫、主題測驗設定、學生作答紀錄、全域設定（JSON 格式，換電腦教學時整份複製即可保留資料）。
- `tools/RPG答題遊戲/assets/images/custom/`：教師自訂上傳的圖片。

## 🧩 WEB 區網互動工具箱（剛好系列）

免設定的**區域網路互動教學伺服器與學生作業繳交系統**，內建 4 套「剛好」即時互動教學模組，以及作業繳交、心智圖、配對遊戲、閱讀測驗生成等多項教學輔助工具，適合**日常課堂互動與作業管理**。

### 核心特色

- **內建本地即時資料庫**：以 `local-firebase.js` 模擬 Firestore 介面，資料實際寫入教師端本機 JSON 檔案，免 Firebase、免網路帳號，區網離線也能多人即時同步。
- **iPad／瀏覽器語音錄製**：即時計時器、錄音動態紅燈、回放試聽、重新錄音，一鍵上傳。
- **課堂教材一鍵截圖繳交**：`www/html/` 下的教材網頁會自動注入浮動「📸 截圖繳交作業」按鈕，學生瀏覽教材時隨時截圖繳交。
- **畫布互動作答**：可在題目背景圖上手繪、多色筆刷、文字框排版，完成後自動截圖繳交。
- **智慧分題收件系統**：學生繳交時選題號＋姓名，後端自動依題號分類建立資料夾（可自訂題號選單）。
- **華麗作業展示牆**：適合教室大螢幕／電子白板展示與課堂講評。
- **教師管理防護**：首頁左下角齒輪圖示輸入管理密碼（預設 `tpet`）解鎖管理工具。

### 「剛好」系列四大即時互動模組

透過教室代碼建立／加入課堂，多人即時同步：

- **🙋 剛好學**：搶答（判定最快送出者）、快速投票（可匿名，即時統計圖）、便利貼牆（依時間分組即時呈現）、閱讀測驗（作答並統計正確率）、作品觀摩投票（按讚統計人氣）。
- **📋 剛好白板**：多人即時協作數位白板，可切換／新增多頁畫布，支援離開保留資料或清空重來。
- **📊 剛好簡報**：上傳 PDF 自動轉檔，教師控制翻頁即時同步全班畫面，並可查看學生即時回饋、匯出簡報資料。
- **📝 剛好測**：線上測驗，支援手動或 AI 輔助出題、即時作答統計分析（含成績分佈圖），成績可匯出 CSV。

## 🖍️ 螢幕畫筆‧截圖互動

免雲端、免帳號的課堂互動工具：**老師在觸控大屏上畫記、框選畫面截圖出題，學生用 iPad 掃 QR Code 即時作答**，特別適合搭配互動電視／電子白板的**當堂即時問答與板書講解**。

### 核心特色

- **螢幕畫筆**：凍結目前畫面直接畫記，提供白板／黑板、直線、方塊、圓形（實心／空心）、橡皮擦、復原、存檔。
- **截圖出題**：框選畫面任一區域，發送為**塗鴉題／選擇題／簡答題／計算題**給全班。
- **即時儀表板**：學生送出後立即顯示，不需重新整理；支援放大展示、多份並排比較、一鍵下載。
- **課堂節奏控制**：🎲 從已回應學生中隨機抽人、⏸ 暫停作答、🔁 同一張截圖重新作答。
- **繪圖過程重播**：在截圖背景上逐筆重現學生作畫過程，可切換 1×／2×／3× 速度。
- **題庫**：課前先截好題目、設定題型存起來，上課一鍵派送；可匯出／匯入 ZIP（含截圖原檔）與其他老師分享。
- **觸控大屏最佳化**：按鈕大、面板可拖曳收合，依螢幕解析度（含 4K）自動調整大小。
- **iPad 最佳化**：支援 Apple Pencil 與手指作畫、自動避免手掌誤觸，工具列可收合。

### 四種題型

| 題型 | 說明 |
|------|------|
| 🎨 塗鴉題 | 截圖全螢幕呈現，畫筆／螢光筆／橡皮擦、9 色、4 種粗細、復原重做；支援 Apple Pencil 自動忽略手掌誤觸 |
| 🔤 選擇題 | 題目下方 A／B／C／D 四色塊點選送出 |
| 📝 簡答題 | 輸入框作答（最多 300 字） |
| 🧮 計算題（多頁計算紙） | 適合數學：預設 4 張格線計算紙，可無限增頁（最多 20 頁），可放大單頁書寫、翻頁看前一頁參考、Apple Pencil 自動切換純筆模式，送出後老師收到總覽圖與每頁完整解析度圖片 |

### 儀表板功能

依題型分別呈現作品卡片牆（塗鴉，可全螢幕逐一展示、選取比較、繪圖重播）、每人一張總覽卡（計算題，可翻頁放大）、A～D 長條圖（選擇題，可隱藏姓名）、卡片或文字雲（簡答題，可逐一投影展示）。所有題型皆可下載作答（塗鴉／計算為 ZIP，選擇／簡答為 CSV），並提供 🎲 抽人、⏸ 暫停作答、🔁 重新作答等課堂控制。

### 使用方式

1. 從整合啟動中心按「▶ 啟動」（或執行 `啟動程式.bat pen`），會出現可拖曳的浮動主面板。
2. 主面板可「🖊️ 開始繪圖」進入畫記模式，或直接「✂️ 截圖出題」框選畫面出題；出題後選擇題型，按「🚀 發送任務」全班立即收到，或「💾 存入題庫」先存起來不發送。
3. 點「📱 連線」顯示 QR Code 與網址，學生用 iPad／平板相機掃描或在 Safari 輸入網址，輸入姓名／座號加入課堂。
4. 點「📊 儀表板」查看即時作答結果，可抽人、暫停、重新作答或下載。
5. 點「📚 題庫」可課前預存題目，上課一鍵派送。

### 資料儲存位置

- `tools/螢幕畫筆截圖互動/題庫/`：`presets.json`（題目清單）＋ `images/`（截圖原檔），可匯出成 ZIP 備份或分享。
- `tools/螢幕畫筆截圖互動/畫記存檔/`：按「💾 存檔」時儲存的畫記圖片（執行時自動建立）。
- 所有學生即時作答資料只存在記憶體中，關閉程式或送出新題目即清除；只有主動下載或存檔才會變成檔案。
