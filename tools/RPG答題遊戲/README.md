## 📖 遊戲背景與特色介紹

每年春分時節，數十萬隻紫斑蝶自高雄茂林等溫暖山谷甦醒，沿著中央山脈西麓一路北返繁衍，形成世界唯二的越冬型蝴蝶奇蹟！  
在《紫斑之翼：奇幻大遷徙》中，學生將化身為蝶群守護勇者，一路克服逆風、天敵與各種關卡魔王挑戰，透過解答各科知識累積能量，協助蝶群平安抵達苗栗與八卦山繁殖聖地。

### 🌟 核心遊戲特色

1. **活潑可愛的鳥山明動漫 JRPG 風格**：
   - 圓潤 Q 彈按鈕、果凍膠囊血魔條（HP/MP）、3D 糖果泡泡選項與微動畫互動回饋。
   - 擺脫枯燥冰冷的傳統測驗卷，讓學生在沉浸式戰鬥闖關中自然提升學習專注力與動力！

2. **四大紫斑蝶生態守護勇者**：
   - 依據台灣常見四種紫斑蝶真實形態特徵與辨識口訣設計：
     - 🦋 **小紫（幻紫遊俠）**：口訣「小紫點一邊」，擅長幻紫瞬光與超高爆發傷害。
     - 🛡️ **阿圓（圓翅巨盾戰士）**：口訣「圓翅兩邊點」，高體力與全方位堅固護盾。
     - 🧙 **阿斯（斯氏靈智賢者）**：口訣「斯氏有三點」，高魔力與全隊生命滋養回復。
     - 🗡️ **端端（端紫幻影刺客）**：口訣「端翅亂亂點」，高敏捷與視線幻惑破防打擊。

3. **台灣遷徙大地圖自由探索**：
   - 包含五大關卡舞台：**茂林幽谷**、**月世界惡地**、**濁水溪河谷**、**國道生態廊道**至**繁衍聖林**。
   - 支援鍵盤 WASD / 方向鍵行走或點擊地圖任意地點即時尋路移動，並具備右下角快速更換出戰角色面板。

4. **各關卡專屬 BGM 音樂與音效引擎**：
   - 進入每一關對峙舞台時自動切換該關卡專屬背景音樂與音效，營造身歷其境的冒險史詩感。

本系統近期迎來多項重量級功能升級，大幅強化遊戲流暢度與課堂實戰體驗：

### 1. 🚪 雙入口主畫面（首頁獨立分流）
- 開啟首頁時呈現大氣雙入口設計：
  - **🎮 進入遊戲**：點擊後進入學生準備視窗，輸入姓名、選擇四大勇者與測驗主題後開始冒險。
  - **⚙️ 教師 / 管理者題庫後台**：教師可直接輸入密碼進入後台備課，不干擾學生作答流程。

### 2. ⏳ 答題倒數秒數與動態進度條（魔王自動反擊機制）
- 戰鬥介面中央計時秒數下方新增**視覺化漸層動態進度條**（綠色 $\rightarrow$ 橙色 $\rightarrow$ 紅色）。
- **倒數歸零威脅機制**：當進度條跑到 0 秒時，魔王怪物會立即自動揮動武器反擊並扣除勇者生命值，有效激發學生作答時的專注力與緊張感！

### 3. 🎲 題庫隨機亂序出題（防止死記順序）
- 進入對戰答題時，系統會**自動將題庫順序隨機打亂**。
- 每次重複闖關或不同學生連線時題目順序皆不同，杜絕學生背答案位置，落實真正的觀念理解。

### 4. 🏆 五關全破過場動畫與手動結算報告跳轉
- 通關第五關後，自動播放四大紫斑蝶守護勇者齊聚同框的史詩通關過場動畫。
- **取消強制自動跳轉**：動畫播畢後畫面停留在勝利慶祝畫面，方便教師與全班同學合影留念；學生或教師手動點擊**「📜 進入成果報告書」**按鈕後，才會正式跳轉至個人結算與錯題檢討頁。

## 🚀 快速開始與使用方式

本專案提供綠色一鍵啟用機制，無須複雜的指令即可快速啟動：

### 步驟一：一鍵啟動伺服器
1. 下載或 Clone 本專案至電腦本機。
2. 雙擊點擊目錄中的 **`啟動程式.bat`**。
   - 程式會自動偵測本機 Python 環境；若尚未安裝，腳本將自動下載並完成輕量安裝。
   - 自動檢查並安裝所需套件（`PyQt5`、`qrcode`、`Pillow` 等）。
   - 自動開啟圖形化伺服器控制面板與瀏覽器視窗。

### 步驟二：區網多人連線（平板、手機、電腦皆可）
1. 在伺服器控制視窗中，點擊 **「顯示 QR Code」** 按鈕。
2. 螢幕將放大顯示專屬連線 **QR Code** 與 **區網 IP 網址**（例如 `http://192.168.1.100:8888`）。
3. **學生在同一教室區網（Wi-Fi 或有線網路）下**，直接拿起平板或手機掃描 QR Code，即可立即連入遊戲！
4. 伺服器支援**全班多人同時在線遊玩與作答**，作答紀錄即時回傳教師後台。

> 💡 **連接埠（Port）彈性更換**：  
> 若預設的 `8888` 埠被其他應用程式佔用，可直接於控制面板下拉選單切換至常用連接埠（如 `8080`, `8000`, `5000`, `3000` 等），點擊「重新啟動伺服器」即可一鍵切換。

## 🎯 教師 / 管理者題庫後台功能詳解與操作指南

點擊主畫面首頁或大地圖左上角的 **「⚙️ 教師 / 管理者題庫後台」** 按鈕，輸入預設密碼 **`admin`** 即可進入全方位管理後台。後台共規劃五大功能模組：

```
教師 / 管理者後台
├── 📚 題庫管理與派送     (CSV 匯入 / Gemini AI 出題 / 線上題目編輯器)
├── 🎯 主題測驗管理       (多題庫自由組卷 / 測驗啟用與停用切換)
├── 📊 學生作答分析與錯題本 (作答歷程 / 錯題難度排行榜 / 課堂全螢幕簡報模式)
├── 🦋 勇者與關主數值調整  (四大勇者與五大魔王 HP/MP/攻防數值自訂平衡)
└── 🖼️ 自訂圖片與 AI 生圖 (20張圖片單圖/ZIP上傳 / 雙向回退 / 免費AI Prompt產生器)
```

---

### 模組一：📚 題庫管理與派送

本系統**不局限於生態題目**！各學科（國語、數學、英文、自然、社會等）教師皆可自由建立專屬題庫：

1. **建立與管理題庫分組**：
   - 點擊「新增題庫」，輸入題庫分類名稱（如「期中數學複習」、「台灣地理風土」）。
   - 支援題庫的編輯、刪除與題目統計。
2. **標準 CSV 檔案一鍵匯入**：
   - 支援標準試算表 CSV 批次匯入，格式規範如下：
     ```csv
     題目,正確答案(1-4),選項1,選項2,選項3,選項4,題目解析(選填)
     台灣越冬型蝴蝶是哪一種？,2,鳳蝶,紫斑蝶,粉蝶,弄蝶,紫斑蝶每年春季會進行北返大遷徙。
     ```
3. **🤖 Gemini AI 出題小幫手（一秒出題）**：
   - 內建專用 AI Prompt 模板。
   - 點擊「複製出題 Prompt」，將課堂教材重點貼給 Google Gemini 或 ChatGPT，AI 即自動產生標準格式題目，直接複製貼入後台即可瞬間完成出題！
4. **線上題目編輯器**：
   - 點擊各題庫旁的「✏️ 編輯題目」，即可逐題檢視題目文字、調整四個選項內容、設定正解編號與填寫補充詳解。

---

### 模組二：🎯 主題測驗管理

1. **自由勾選組合題庫（彈性組卷）**：
   - 教師可建立多組主題測驗（例如：「全班隨堂小考」、「第三單元生態闖關」）。
   - 支援跨題庫複選：可將「基礎觀念題庫」與「進階挑戰題庫」一鍵合併為同一次測驗。
2. **「啟用 / 停用」切換開關**：
   - 當前不想開放給學生施測的考卷，點擊切換為「已停用」。
   - 學生端登入時的主題選單將**自動隱藏已停用的測驗**，避免學生提前偷看或選錯考卷。

### 模組三：📊 學生作答分析與錯題本

結合大數據統計分析，協助教師落實差異化教學與精準教學補救：

1. **學生作答名冊與歷程（子分頁一）**：
   - 依時間降序即時列出作答學生：姓名、選擇角色、總分、答對題數、作答時間。
   - 點擊「檢視詳細」可展開該學生每一題的作答歷程（包含答對標記、選取之選項內容）。
   - 提供個別記錄刪除與「清空所有紀錄」功能。
2. **錯題難度排行榜（子分頁二）**：
   - 系統自動彙整全班數據，**依照「答錯人數由多到少」自動排序**。
   - 每題呈現全班答對率長條圖、四個選項個別被選取的人次分佈。
   - 列出具體**答錯學生名單與其所選的錯誤選項**，幫助教師立即掌握學生的迷思概念盲點。
3. **🖥️ 課堂討論全畫面簡報模式（Presentation Mode）**：
   - 專為大螢幕與教室投影機打造的互動檢討工具：
     - 點擊「進入簡報模式」即可切換至全螢幕大字體投影片。
     - **「隱藏 / 顯示答案」功能（快捷鍵 `H`）**：先投影題目請全班思考發表，再一鍵亮出正確答案。
     - 整合概念詳解說明卡與誤選學生名單卡。
     - 支援鍵盤導航：`←` / `→` 切換題目、`ESC` 隨時退出簡報。

### 模組四：🦋 勇者與關主魔王數值調整

依據學生程度與課堂節奏，隨時客製化遊戲難易度：

1. **四大紫斑蝶勇者數值設定**：
   - 可分別微調小紫、阿圓、阿斯、端端的「基礎生命值（HP）」、「魔力值（MP）」與「攻擊力（ATK）」。
   - 支援調整各勇者專屬主動大招的傷害係數與 MP 消耗。
2. **五大關主魔王難度微調**：
   - 可分別自訂綠色史萊姆、沙漠幻影蝶、暴風雪怪、黑翼蝠王與終極毒蠍魔王的 HP、普通攻擊力與爆擊機率。
   - 一鍵「儲存數值設定」即刻生效，亦可點擊「恢復原廠預設」一秒重置。

### 模組五：🖼️ 遊戲全域視覺美術與自訂圖片取代中心

本系統具備業界罕見的**全域視覺自由更換引擎**，教師可將遊戲徹底改造為任何教學主題（如：歷史三國、外太空探險、海洋生物、成語冒險等）：

#### 1. 全域 20 張視覺圖片清單
系統精準涵蓋遊戲中所有 20 個標準視覺圖片：
- **四大勇者戰鬥全身立繪（4張）**：`hero_sprite.png`（小紫）、`hero_sprite_round.png`（阿圓）、`hero_sprite_syl.png`（阿斯）、`hero_sprite_mul.png`（端端）
- **四大勇者特寫頭像（4張）**：`avatar_purple.png`（小紫）、`avatar_round.png`（阿圓）、`avatar_syl.png`（阿斯）、`avatar_mul.png`（端端）
- **五大關主魔王立繪（5張）**：`slime_sprite.png`、`mirage_sprite.png`、`demon_sprite.png`、`boss_sprite.png`、`frost_sprite.png`
- **五大戰鬥背景（5張）**：`forest_bg.jpg`、`desert_bg.jpg`、`river_bg.jpg`、`highway_bg.jpg`、`sacred_bg.jpg`
- **兩大全域遊戲背景（2張）**：首頁主背景（`title_bg.jpg`）、遷徙大地圖背景（`world_map.jpg`）

#### 2. 三大圖片置換方式
- **方式一：單圖上傳取代**：在後台 20 張卡片中找到對應圖片，點擊「上傳自訂圖片」即可單張替換。
- **方式二：📦 ZIP 壓縮檔批次取代**：
  - 將生成好的圖片命名為標準檔名（如 `avatar_purple.png`、`forest_bg.jpg` 等），直接打包為 `.zip` 壓縮檔。
  - 點擊「壓縮檔批次上傳 (.zip)」，系統自動解壓縮並比對符合的檔名進行取代，其餘非系統圖片自動略過。
  - 後端內建**防禦性目錄自動建立機制**，完全無目錄缺失風險。
- **方式三：🔄 還原原廠預設**：支援個別圖片「恢復預設」或「全系統 20 張圖片一鍵恢復官方預設」。

#### 3. 🔄 雙向智慧回退機制（Two-way Smart Fallback）
- **只上傳全身立繪**：系統自動將特寫頭像連動套用該自訂立繪，選角畫面、大地圖與通關動畫同步生效！
- **只上傳特寫頭像**：系統亦自動將戰鬥舞台立繪連動套用該自訂頭像，無需手動補圖！
- **兩者皆上傳**：各自呈現獨立設定的美術圖。

#### 4. ⚡ 20 張全套生圖 Prompt 模板產生器（AI Agent 一鍵生成專用）
- **免呼叫任何外部收費 API**，純前端本地即時運算！
- **操作步驟**：
  1. 輸入或點選**【視覺風格】**（如：鳥山明熱血動漫風、吉卜力水彩、賽博龐克、像素復古、東方仙俠水墨等）。
  2. 輸入或點選**【故事主題】**（如：台灣紫斑蝶生態遷徙、深海古文明探險、宇宙星際冒險、三國英雄演義等）。
  3. 系統立即套用最佳尺寸、去背透明背景與構圖規範，瞬間產出 20 張圖片對應的繁體中文 Prompt 與標準固定檔名。
  4. 點擊**「📋 一鍵複製全套 20 張指令」**，直接送交 AI 工具（如 Claude、ChatGPT、Midjourney 等）批次產圖，下載打包成 ZIP 後直接於後台上傳，5 分鐘即可完成整套遊戲主題換膚！

## 📁 本地檔案儲存結構

所有遊戲設定、題目與學生作答紀錄皆保存於本機端，無須安裝 MySQL 等龐大資料庫，資料隱私安全且好備份：

| 檔案路徑 | 類型 | 說明 |
| :--- | :--- | :--- |
| `Game-data/question-banks/` | JSON | 各題庫題目內容、選項、答案與詳解說明 |
| `Game-data/exams/` | JSON | 主題測驗配置（測驗名稱、綁定題庫組、啟用/停用狀態） |
| `Game-data/student-records/` | JSON | 學生作答成績清單（姓名、得分、答對題數、作答歷程） |
| `Game-data/config.json` | JSON | 全域遊戲設定（自訂數值平衡、圖片置換路徑對應表） |
| `assets/images/custom/` | 圖檔 | 教師上傳之自訂圖片存放目錄（具備 .gitkeep 結構保護） |
| `server.py` | Python | 輕量 Python HTTP 伺服器與 RESTful API 服務 |
| `web_exe2.py` | Python | PyQt5 桌面控制面板、Port 切換與 QR Code 產生器 |
| `啟動程式.bat` | 批次檔 | Windows 一鍵啟動腳本（自動化環境安裝與程式啟動） |
